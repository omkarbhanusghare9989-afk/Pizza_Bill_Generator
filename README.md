🍕 Pizza Bill Generator

A simple Pizza Bill Generator project that allows users to select pizzas, choose quantity and toppings, and automatically calculate the final bill.

📌 Project Description

The Pizza Bill Generator is designed to make pizza billing simple and fast.
The user can select a pizza, add extra toppings or cheese, choose the quantity, and generate the total bill.

This project is useful for understanding input handling, conditional statements, calculations, and bill generation.

✨ Features

- Select different types of pizzas
-  Choose pizza size
-  Add extra cheese
-  Add extra toppings
-  Select quantity
-  Automatically calculate total price
-  Generate a final bill
-  Handles invalid selections

🛠️ Technologies Used

- Programming Language: Java
- Object-Oriented Programming (OOP)
- IDE:Eclipse
